# Peppol-utils Knowledge Base

This public repository separates source documents from the generated,
application-consumable Knowledge Base distribution:

- [`France CTC`](France%20CTC/) contains the France CTC reference documents.
- [`Peppol-Utils Knowledge base`](Peppol-Utils%20Knowledge%20base/) contains
  versioned Knowledge Base bundles, checksums, build reports, and the signed
  stable-channel manifest used by Peppol-utils.

Published Knowledge Base artifacts are authenticated by the Peppol-utils
desktop application before installation. The signing private key is not stored
in this repository.
