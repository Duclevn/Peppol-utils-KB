# Peppol-utils Knowledge Base

This public repository separates source documents from the signed, application-consumable Knowledge Base distribution:

- [`France CTC`](France%20CTC/) contains the France CTC reference documents.
- [`Peppol-Utils Knowledge base`](Peppol-Utils%20Knowledge%20base/) contains the signed stable-channel manifest, build report, evaluation report, and distribution guidance.
- [GitHub Releases](https://github.com/Duclevn/Peppol-utils-KB/releases) contains the current downloadable bundle.

The only supported build is schema-v2 bundle `2026.07.30.3`, published as release [`kb-v2026.07.30.3`](https://github.com/Duclevn/Peppol-utils-KB/releases/tag/kb-v2026.07.30.3). Previous schema-v1 downloads have been withdrawn.

Peppol-utils authenticates the signed manifest and verifies the bundle size and SHA-256 before installation. The signing private key is not stored in this repository.
